# slc-rtc-lookup

Library for connecting Sentinel-1 SLC granules, OPERA burst IDs, and OPERA RTC-S1 products for OPERA RTC-S1 accountability.

## Installation

```bash
# Create conda environment
mamba env create -f environment.yml
conda activate s1-slc-rtc-lookup

# Install package
pip install -e .
```

See the jupyter notebook for checking spatiotemporal subsets for SLCs and their corresponding RTC-S1 products.
